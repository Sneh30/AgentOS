## Glass morphism (applied this session)

On top of the Graphite palette, surfaces that float above other content use a translucent + blurred "glass" treatment instead of solid fills:

| Component | Treatment |
|---|---|
| `Card` (`src/components/ui/card.tsx`) | `bg-card/70 backdrop-blur-xl` |
| `Sidebar` (`src/components/layout/sidebar.tsx`) | `bg-sidebar/70 backdrop-blur-xl` |
| `DialogContent` (`src/components/ui/dialog.tsx`) | `bg-popover/80 backdrop-blur-2xl` |
| `SheetContent` (`src/components/ui/sheet.tsx`) | `bg-popover/85 backdrop-blur-2xl` |
| `BottomNav` (already glass pre-existing) | `bg-background/80 backdrop-blur-xl` |

A subtle radial-gradient glow (`color-mix(in oklch, var(--foreground) 3-4%, transparent)`) is painted behind the `.light`/`.dark` theme root in `globals.css` so the blurred glass surfaces have something visible to reveal — flat solid backgrounds make backdrop-blur invisible.

**Do:** keep glass surfaces to things that actually float over other content (sidebars, modals, sheets, sticky headers, cards over the page background). **Don't:** stack multiple blurred layers on top of each other (double-blur reads muddy, not premium) — a glass card inside a glass sidebar should drop the inner blur.

### Type scale (recommended)

| Role | Class | Use |
|---|---|---|
| Display | `text-5xl font-semibold tracking-tight` | Hero only, one per page |
| H1 (page) | `text-3xl font-semibold tracking-tight` | Page title |
| H2 (section) | `text-xl font-semibold` | Section breaks |
| H3 (subsection) | `text-base font-medium` | Card titles |
| Body | `text-sm` | Default UI text |
| Small / caption | `text-xs text-muted-foreground` | Meta, timestamps |
| Mono | `font-mono tabular-nums` | Numbers, counters |

Headers use `font-semibold`, not `font-bold` (already applied across the app) — lighter hierarchy, less shouty.

## Tone and voice

Blend of **technical** and **premium** (the two moods picked for Anymind):

### Words to use

Direct, specific, number-forward, factual. Prefer verbs over adjectives, nouns over metaphors. Confident and understated — describe things with restraint ("connected your inbox" not "unlocked email superpowers"). When describing an action, say what it does, not what it feels like.

### Words to avoid

Hype words (revolutionary, game-changing, unleash, supercharge, "unlock"), emojis, exclamation marks, overpromising, "luxury"/"exclusive"/"elite" (using them makes it less premium, not more).

### Voice example

> Connected Gmail. 312 calls today, 98.4% success. Nothing needs your attention.

## Usage dos and don'ts

**Do:**

- Use the shadcn CSS variables (`bg-background`, `text-foreground`, `bg-primary`) everywhere. Never hardcode hex.
- Keep the 4px spacing grid (`gap-2`, `p-4`, `px-6`).
- Use `font-mono tabular-nums` for any number that updates in place (task counts, stats).
- Test every component in both light and dark mode (`.light` / `.dark` class) before considering it done.
- Reserve glass (`backdrop-blur`) for surfaces that float over other content — see the Glass morphism section above.

**Don't:**

- Hardcode colors (`#FF0000`, `rgb(...)`) in component files.
- Use `transition: all` — always specify `transition-colors`, `transition-transform`, etc.
- Introduce hue/saturation into the core UI — Graphite is intentionally grayscale. Chart colors are the one sanctioned exception.
- Stack multiple `backdrop-blur` layers on top of each other.
- Override shadcn tokens per-component — if a color is wrong, fix it in `globals.css` once.
