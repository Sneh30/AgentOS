
Problem statement:

Sales and marketing teams juggle a dozen disconnected tools — CRM, email, LinkedIn, calendars, enrichment data — and burn hours a week on manual busywork like finding prospects, sending outreach, and updating records across all of them. Existing AI tools either can't take real action in these apps or don't remember anything between sessions, so the same context gets re-explained every time. gtm-os fixes this by giving GTM teams one workspace where an AI agent has persistent memory and can actually act across their connected apps and the open web.


what we have used:

1) Crustdata YC'24 (Fall)'s claude gtm skills - Crustdata provides live company and people data via APIs and full dataset delivery. We make hard to get data easy to use at scale.

2) Composio to connect via mcp of all GTM tools - Slack, Linkedin, X, etc.
